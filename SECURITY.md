# Security policy

Report vulnerabilities in this repository through [Arachne's private security
reporting form](https://github.com/arachne-systems/arachne-core/security/advisories/new).
Name this repository, the affected commit/version, impact, reproduction steps,
and any workaround. Do not open a public issue for an undisclosed vulnerability
or include live secrets, invitations, keys, or operational data.

Expect acknowledgement within 3 business days, initial triage within 7 calendar
days, and an update at least every 14 calendar days while remediation is active.
Coordinated disclosure normally occurs within 90 days and may be faster during
active exploitation.

Until the first stable release, only the latest published prerelease and this
repository's designated trunk receive security fixes. Older snapshots and
unmerged feature branches are unsupported.

The shared form must be enabled on `arachne-core` before release. An unavailable
private reporting path blocks release.
